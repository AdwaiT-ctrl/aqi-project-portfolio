Introduction

The project starts with the public health importance of AQI and the need to make air quality patterns easy to understand.

Naive Bayes

Decision Trees

Regression

Logistic regression gives a clean binary baseline and pairs well with the probabilistic models used in the assignment.

The biggest takeaway is that air quality problems are not just about one pollutant or one day. They are shaped by repeated patterns in the data, and those patterns become clearer when the project combines visualization, classification, and side-by-side model comparison.

In the validated run inside this workspace on the attached AQI dataset, logistic regression was the strongest classifier at 0.9093 accuracy, while the best Naive Bayes variants reached 0.8871. The tree model also performed well at 0.8968, which makes the final ranking close enough that the model choice should be justified by interpretability as well as score.

If I were extending the project further, I would keep the same feature table and add more tuned comparisons, such as deeper tree pruning, feature selection, and a stricter evaluation of which pollutant groups are most informative for classification.
